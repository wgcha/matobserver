# 결정 기록

확정된 결정을 날짜·근거와 함께 한 줄씩 누적한다.

- 2026-10-24 · 저장소·패키지명 `matobserver` — MatNexus와 짝을 이루는 역공학(FEMU) 엔진, 관측 데이터로 숨은 물성을 식별
- 2026-10-24 · 구현 단계: 1차 3점굽힘, 2차 압축, n차 전단·고속·임의 시험 — 데이터 교류 계약은 1차에서 n차 기준으로 확정하고 이후 추가만(하위 호환, `schema_version`)
- 2026-10-24 · 플러그인 5종 분리: 최적화기, 솔버 어댑터, 재료카드, 형상·메시, TestSpec — 교체 시 엔진 무수정
- 2026-10-24 · 1차 산출물은 솔버 중립: E, ν(입력 기록), 진응력–진소성변형률 테이블 + 유효 범위·시험 종류·가정·잔차 메타데이터 — 타 솔버 적용, LS-DYNA 카드는 2차 산출물
- 2026-10-24 · 기본 재료카드 MAT_001(E), MAT_024(탄소성), 그 외 옵션 플러그인 — 대상 재료 전반(플라스틱·금속·실리콘·유리·IC PKG)
- 2026-10-24 · 시험 데이터 입력은 MatNexus 어휘(SI) 채택, 별도 중립 포맷 미정의 — MatNexus가 시험종류·채널·치수를 이미 표준화
- 2026-10-24 · MatNexus는 수정하지 않는다 — 결과 반입 경로(ADR 0026 inverse 등)는 협의 사항으로만 둔다
- 2026-10-24 · JobStore는 SQLite, API·워커 프로세스 분리, 워커 1개 — 로컬 단일 PC·최대 4코어, 별도 DB 서버 불필요
- 2026-10-24 · 대용량 파일만 작업 폴더, 외부에는 `artifact_id`(`GET /v1/artifacts/{id}`)로만 제공, 경로 비노출
- 2026-10-24 · API에 `POST /v1/files`, `GET /v1/calibrations`(목록), `GET /v1/artifacts/{id}` 추가
- 2026-10-24 · STP 메시는 오픈소스 메셔(gmsh 등), LS-DYNA 키워드 writer는 자체 작성 — 형상 단순, 사면체/2D로 충분
- 2026-10-24 · 솔버 실행은 사내 배치 스크립트(SMP/MPP)를 어댑터가 래핑 — 배치 정보는 별도 수령
- 2026-10-24 · 시험·해석 곡선 정렬·재샘플링 8단계 표준 규칙을 1차부터 적용 — 데이터 구간·간격이 제각각
- 2026-10-24 · 고속 시험은 시간 기준축 + explicit 동적, 속도 의존 식별은 n차 — 계약에만 1차 반영
- 2026-10-24 · 압축 마찰계수 μ는 기본 식별 변수(2차) — 윤활 없는 시험이 기본
- 2026-11-08 · 지그·경계조건은 레시피(`recipe_id@version`, 불변)로 관리, 파라미터형 템플릿도 레시피의 한 종류 — 지그 변경 시 코드 무수정, 결과 재현
- 2026-11-08 · 레시피 등록·폐기는 관리자 전용, 1차는 폴더 + CLI(`matobserver recipe add`)와 관리자 토큰 API — 주체 구분 없이 권한으로만 구분, MatNexus 무수정

- 2026-11-08 · 1차에 모드 A 전체 + 모드 B 탄성, 식별성 진단, 다중 시험 동시 피팅 포함 — 다중 슬롯은 단일 곡선으로 비식별
